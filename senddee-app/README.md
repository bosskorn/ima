# Senddee Staff — แอปพนักงานหน้าร้าน (Vue 3 + Capacitor, Android)

เมนูชุดเดียวสำหรับพนักงานทุกคน (ไม่แยกบทบาท) หน้าหลักเป็นตารางไอคอนแบ่ง 4 หมวด เมนูล่าง 5 ช่อง

แอปสำหรับพนักงานร้านตัวแทนรับพัสดุ Senddee: รับพัสดุจากลูกค้า → ออกใบปะหน้า → ส่งมอบให้ขนส่ง → สรุปยอดปิดร้าน
ตอนนี้ใช้ข้อมูลจำลอง (mock) ใน `src/api/index.js` — เมื่อมี backend จริงแก้เฉพาะไฟล์นั้น

## หน้าจอ
| หน้า | ใช้ทำอะไร |
|---|---|
| หน้าที่ | ตารางเมนูทำงาน 2 แท็บ (พนักงานหน้าร้าน / ผู้ดูแลสาขา) ตัวเลขแจ้งเตือนบนไอคอน |
| รับพัสดุ | วางที่อยู่ → แยกชื่อ/เบอร์/จังหวัด/ไปรษณีย์อัตโนมัติ, ชั่งน้ำหนัก, บริการ, COD, รับเงิน → ใบปะหน้า |
| พัสดุในร้าน | เลือกหลายชิ้น → สแกนตรวจนับ → ส่งมอบขนส่ง (ออกใบส่งมอบ) |
| ค้นหา | เลขพัสดุ/ชื่อ/เบอร์, สแกนบาร์โค้ด, ดูใบปะหน้า, Void |
| ปิดยอดเงินสด | นับเงินในลิ้นชักเทียบกับระบบ บันทึกผลต่าง (ไม่มีหน้ารายงาน) |
| เช็คราคา / ข่าวสาร / แจ้งปัญหา | ตามชื่อเมนู |

## รันบนเบราว์เซอร์
    npm install && npm run dev      # เข้าสู่ระบบด้วย S001 + PIN 4 หลักอะไรก็ได้

## สร้าง APK
- เครื่องที่มี Android Studio/SDK: `npm run android:apk` → `android/app/build/outputs/apk/debug/app-debug.apk`
- หรือ GitHub Actions "Senddee Android APK" (Run workflow) แล้วโหลด artifact

## ยังไม่ได้ทำ / ต้องทดสอบบนเครื่องจริง
- สแกนด้วยกล้อง (ML Kit) ต่อโค้ดไว้แล้วแต่ยังไม่ได้ทดสอบบนมือถือ; เครื่องสแกนแบบ keyboard-wedge ใช้ได้เลย
- พิมพ์ผ่านเครื่องพิมพ์ความร้อนบลูทูธ (ตอนนี้ใช้ window.print)
- อัตราค่าส่ง ค่าคอม COD และชื่อบริการเป็นค่าสมมติ

## ฟังก์ชันที่มี
- รับพัสดุ (วางที่อยู่แยกอัตโนมัติ, COD, วิธีรับเงิน), ใบปะหน้า + บาร์โค้ด, พิมพ์ซ้ำ
- แก้ไขพัสดุก่อนส่งมอบ (คำนวณเก็บเพิ่ม/คืนเงิน), ยกเลิก (Void) พร้อมเหตุผล, แชร์เลขพัสดุให้ลูกค้า
- พัสดุในร้าน: เลือกหลายชิ้น, สแกนตรวจนับ, ส่งมอบขนส่ง + พิมพ์ใบส่งมอบ, กรองค้างเกิน 24 ชม.
- ค้นหา/กรองสถานะ, เช็คราคา, แจ้งปัญหา (ปิดเรื่องได้), ข่าวสาร, ปิดยอดเงินสด
- ตั้งค่า: ข้อมูลสาขา, เครื่องพิมพ์/ขนาดกระดาษ/พิมพ์อัตโนมัติ, ค่าเริ่มต้นบริการและวิธีรับเงิน

## เรื่องเงิน (สำคัญ)
- แอปนี้ **ไม่รับเงินและไม่มีการปิดยอดเงินสด** ลูกค้าเติมเครดิตกับแฟรนไชส์ไว้ก่อน ตอนสร้างออเดอร์ระบบหักค่าขนส่ง + ค่า COD 3% จากเครดิตผู้ส่ง
- เครดิตไม่พอ = สร้างออเดอร์ไม่ได้ · ยกเลิก (Void) = คืนเครดิต · แก้ไขพัสดุ = หัก/คืนส่วนต่าง
- เมนูตั้งค่าแสดงรายได้วันนี้/เดือนนี้ และกำไรประมาณการ (อัตรา `PROFIT_MARGIN` ใน `src/data/constants.js` เป็นค่าสมมติ)

## การพิมพ์
- ใบปะหน้า 100×150 มม. (หรือ 80 มม. ตั้งค่าได้) และใบรับฝากพัสดุ 80 มม. พิมพ์ผ่านระบบพิมพ์ของ Android — สั่งพิมพ์แต่ละใบแยกหน้าของตัวเอง ไม่พิมพ์ส่วนอื่นของแอป
- ใบรับฝากพัสดุ **ไม่ใช่ใบกำกับภาษี** ใบกำกับภาษี/ใบเสร็จอิเล็กทรอนิกส์ออกโดยระบบ SendDee ทางอีเมล (ตามข้อกำหนดบนเว็บ senddee.com)

## ทดสอบความเชื่อมโยงของข้อมูล
